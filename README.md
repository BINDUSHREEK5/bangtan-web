# Bangtan Boys Fan Website 💜

✨Frontend practice project using HTML, CSS, and hover animations

A simple fan website dedicated to BTS (Bangtan Boys) created using HTML and CSS.  
This project was built as a beginner frontend practice project while learning web development.

---

## ✨ Features
- Responsive landing page
- BTS themed design
- Background blur effect
- Hover effects on images
- Multiple sections with styled text and images
- Clean layout using HTML & CSS only

---

## 🛠️ Technologies Used
- HTML5
- CSS3

---

## 📸 Preview
The website contains:
- Hero section with BTS background image
- Styled typography and headings
- About BTS section
- Interactive image hover effects
